# Support

Use [GitHub Issues](https://github.com/aakashpadhiyar/xdm-macos/issues) for reproducible application and browser-integration problems.

Please include:

- XDM New version
- macOS version and Mac architecture
- Browser and extension versions, when relevant
- Expected and actual behavior
- Reproduction steps
- Sanitized error text

Do **not** include passwords, cookies, authorization headers, private URLs, personal browsing history, or downloaded private media.

This project does not promise compatibility with DRM-protected media or services whose terms prohibit downloading.
