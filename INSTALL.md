# Installation

The current public package is [XDM New 0.0.9](https://github.com/aakashpadhiyar/xdm-macos/releases/tag/0.0.9) for macOS 14 or later.

1. Download the macOS archive only from this repository's Releases page.
2. Compare its SHA-256 checksum with the checksum in the release notes.
3. Extract the archive and move **XDM New.app** to `/Applications`.
4. Launch the application from `/Applications`.
5. Install only the browser-extension version listed for that application release.

FFmpeg may be required for downloads whose video and audio tracks are delivered separately.


Do not bypass macOS security warnings for packages obtained from another source.
