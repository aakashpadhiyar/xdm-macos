BUILT FOR THE MAC

Faster when a server supports it.
Reliable when it does not.

01

Smart connections

Use 1–20 byte-range connections per supported file. XDM New safely falls back to a single connection when a server does not support ranges.

02

Downloads that resume

Paused segments are kept together in a hidden .XDM cache in the chosen download folder, then merged and cleaned after completion.

03

File actions that feel native

Preview partial video, reveal in Finder, open with your default app, or choose another installed macOS application.

04

Control the queue

Choose your appearance, download destination, up to 10 active downloads, and up to 20 connections per download in Settings.

BROWSER INTEGRATION

Bring downloads from the browser to the app.

Install the XDM New browser monitor to send direct browser downloads to the local app. XDM New creates the user-level native browser bridge from Settings; the extension remains off until you enable monitoring.

THE PROJECT

Open source from app to extension.

The project builds on the historical Xtreme Download Manager source while the modern macOS app and loopback Chrome extension are newly written. Complete corresponding source, build instructions, and notices are published on GitHub.
