# XDM New for macOS

XDM New is a macOS-focused download manager inspired by and derived from the historical [Xtreme Download Manager](https://github.com/subhra74/xdm) project.

This single repository hosts the [project website](https://aakashpadhiyar.github.io/xdm-macos/), public release packages, installation guidance, browser-integration documentation, update information, and support resources. Development source and internal history are maintained separately.

> **Current release:** [XDM New 0.0.9 for macOS](https://github.com/aakashpadhiyar/xdm-macos/releases/tag/0.0.9), including browser monitor 0.3.1 packages for Chrome and Firefox.

Never download XDM New packages from unofficial mirrors.

## Capabilities

- Native macOS interface with light and dark appearance
- Segmented downloads with configurable connections
- Pause, resume, retry, queue, and history management
- Browser monitoring for Firefox and Chromium-based browsers
- Streaming-media detection and format selection
- Video and audio merging through FFmpeg where required
- Download-completion notifications, previews, and Open With support
- Menu-bar background monitoring and startup-at-login control
- In-app update checks
