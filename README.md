# XDM New project site

The static GitHub Pages site for [XDM New](https://github.com/aakashpadhiyar/Xtreme-Download-Manager-Releases), a macOS-focused download manager.

The site is published from the `main` branch of this repository at `https://aakashpadhiyar.github.io/xdm-macos/` once GitHub Pages has deployed it.

This site contains no analytics and no third-party JavaScript.

The current download links target the verified `0.0.9` GitHub release and browser monitor `0.3.1` assets.
