# XDM New browser extension packages

This directory is populated by the XDM New macOS build workflow with the portal-upload packages and their SHA-256 checksums.

- `XDM-New-Chrome-extension-<version>.zip` is uploaded to Chrome Web Store.
- `XDM-New-Firefox-extension-<version>.xpi` is uploaded to Firefox Add-ons (AMO) for signing.

Do not describe either archive as a direct installer before its browser-store listing is published.
